# Call Center Performance & Sales Analytics Dashboard | Power BI

## Project Overview

This project is an interactive **Call Center Performance and Sales Analytics Dashboard** developed using Microsoft Power BI.

The dashboard provides insights into call center operations, communication activities, lead management, customer conversion, follow-up performance, and revenue trends.

It enables stakeholders to monitor operational KPIs, evaluate sales performance, identify missed opportunities, and understand how effectively leads are converted into customers.

## Key Performance Indicators (KPIs)

The dashboard provides an overview of the following performance metrics:

| KPI | Description |
|---|---|
| Total Calls Handled | Total number of calls handled by the team |
| Total SMS Sent | Number of SMS messages sent |
| Open Calls | Number of calls currently open |
| Missed Calls | Total number of missed calls |
| Emails Sent | Total number of emails sent |
| Average Response Time | Average time taken to respond to incoming interactions |
| Conversion Rate | Percentage of leads converted into customers |
| Converted to Customer | Number of leads successfully converted |
| Follow-up Success Rate | Percentage of successful follow-up activities |
| Lost Leads | Number of leads lost due to missing follow-ups |
| Successful Call Rate | Percentage of successful calls |
| Calls Followed-Up | Total number of calls receiving follow-up actions |

## Dashboard Visualizations

### 1. Daily Calls Overview

A time-series visualization showing monthly call center performance.

It tracks:
- Total calls handled.
- Calls followed up.
- Missed calls.
- Open calls.

This visualization helps identify changes in call volume and follow-up activity over time.

### 2. Conversion Breakdown

A doughnut chart illustrating the distribution of leads across three stages:

- Leads
- Appointments
- Converted customers

It provides an overview of the lead conversion process and helps evaluate the progression of potential customers through the sales funnel.

### 3. Average Deal Size

A monthly bar chart displaying average deal size.

It helps stakeholders compare deal values across different months and identify periods with stronger sales performance.

### 4. Revenue Trend

A revenue trend visualization tracking monthly revenue performance.

It helps identify revenue growth patterns, fluctuations, and periods of stronger financial performance.

## Interactive Features

- Date range filtering to analyze performance across selected periods.
- Interactive Power BI visualizations.
- KPI monitoring.
- Monthly performance comparisons.
- Lead conversion analysis.
